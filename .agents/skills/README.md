# Development skills

The `tdd` and `diagnosing-bugs` skills originate from [mattpocock/skills](https://github.com/mattpocock/skills), under `skills/engineering/`. They are distributed under the [MIT license](LICENSE), copyright 2026 Matt Pocock.

The installed skill files and their supporting resources are preserved as-is. `skills-lock.json` records the installer source paths and computed hashes; it does not record an upstream commit SHA. Review skill updates and lock changes together before committing them.

These skills provide optional development procedures, not application dependencies. They do not install or execute themselves. Follow repository instructions and explicit user authorization when applying them. References to other skills (such as `codebase-design` or `code-review`) do not imply those skills are installed; the two project reviewers are documented separately in `.codex/agents/README.md`.
